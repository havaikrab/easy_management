# Easy Management

## Описание

Easy Management - система контроля исполнения задач, поставленных перед сотрудниками организации.  
Основные возможности:
- Постановка задач
- Прямое назначение исполнителя
- Автоматическое назначение исполнителя из потенциальных кандидатов
- Мониторинг состояния готовности
- Разделение ответственности за исполнение отдельных составляющих одной основных задач
- Распределение прав руководитель-подчиненный, создатель-исполнитель задачи
- Равномерное распределение ответственности между исполнителями
- Подробное отображение структуры и состояния готовности подзадач

Данная система предназначена для использования ограниченным кругом лиц, а именно,
сотрудниками одной организации. Правом регистрации новых пользователей обладает также
ограниченный список лиц, как правило, это сотрудники "отдела кадров". Учетная запись
сотрудника содержит минимальную информацию о нем и служит лишь своего рода
"подписью" ответственного исполнителя или создателя задачи.  
Основная цель Easy Management - разделение глобальных задач организации на более
мелкие, что позволяет распределить ответственность между сотрудниками. В свою очередь,
мониторинг структуры задач позволяет выявить отсутствующие элементы
в последовательности событий, которые должны привести к успешному достижению целей организации.

## Запуск

Так как регистрация новых пользователя ограничена узким кругом лиц, при первом
запуске приложения предусмотрена возможность создать супер-пользователя, который
сможет беспрепятственно "войти в систему" первым, зарегистрировать других пользователей
и "раздать" им соответствующие права. Для создания первого супер-пользователя в
переменных окружения на машине, с которой будет запущено приложение, нужно указать все необходимые
настройки. Подробное описание настроек приведено в файле .env_template. После успешного запуска
необходимо удалить или установить флаг CREATE_SUPER_ADMIN в положение False. Это позволит
перезапускать сервер без ошибок. При запуске с "включенным" флагом CREATE_SUPER_ADMIN и указанием
неполных данных нового супер-пользователя или с указанием существующего в системе SUPER_ADMIN_NAME
возникнет ошибка, и запуск будет остановлен.
Для запуска docker-контейнера с приложением необходимо разместить содержимое папки deploy в рабочей
директории, создать там же файл .env с переменными окружения и выполнить команду
docker compose up.
После успешного запуска супер-пользователь, чьи данные были указаны в .env-файле, должен:
- Войти в админ-панель приложения, используя указанные им данные
- Описать основные должности организации
- Создать учетные записи для других ключевых лиц организации
- Назначить при необходимости другим пользователям нужные права.  
- 
Права:
- add_activity - наделяет пользователя возможностью описывать новые должности и устанавливать
между ними взаимосвязь.
- view_activity - наделяет пользователя возможностью регистрировать новых пользователей и иметь
оперировать объектами должности без возможности их создания, изменения или удаления.
- view_quest - открывает для пользователя возможность изучения "дерева зависимостей задач".
